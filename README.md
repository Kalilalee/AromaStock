# Aroma Stock

Tienda de perfumes para Aplicaciones Móviles, desarrollada con React Native y Expo.

## Ejecutar

```bash
npm install
npm start
```

Abrir el proyecto con Expo Go escaneando el QR del servidor. Las cuentas, el carrito, los favoritos y el historial de pedidos se guardan localmente con AsyncStorage.

Para ejecutar las pruebas:

```bash
npm test
```

## Funcionalidades

- Registro e ingreso local con usuario y contraseña.
- Tienda con seis perfumes y fichas de producto.
- Carrito con cantidades, total y confirmación de pedido de demostración.
- Perfil con edición del nombre, foto, favoritos, historial de pedidos y cierre de sesión.
